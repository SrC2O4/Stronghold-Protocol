# 六星甄选机制适配

## 状态与边界

78 名新增候选的 234 个技能已经接入各自的自动战斗适配。原有 59 名固定池六星仍使用原先的实现。数值读取当前选中技能、普通／精锐和模组对应的黑板；没有黑板的部分参数使用描述中的数值或明确的网页适配值。

**这是一版可运行的二创战斗适配，不是全机制完成或原作等效认证。** 技能有专属入口、模拟不报错、模型能显示，都不能代替逐项效果验证。调配界面展示原作技能说明；`kit-coverage` 的全覆盖仅指存在专属 spec。

## 已接入的主要系统

- 主从联动：凯尔希的治疗优先级、Mon3tr 范围内外防御、群攻／真伤／衰减及未击杀扣血；麦哲伦无人机技能增益与回收；傀影虚影独立增益层数；令的召唤物合并；死芒的仆役生成和升级。
- 场地与装置：W 地雷、多萝西共振装置、艾拉地雷、望的相连棋子触发；白铁与娜斯提的前方支援、鸿雪打字机、温蒂蓄水炮、杰西卡盾牌、莱伊侦察范围；新型装置按主人所带技能选择行为。
- 状态与持续技能：煌的锁血、赫拉格／左乐低血增益、年护盾、林的伤害阈值屏障、斥罪屏障、棘刺／提丰等二次技能常驻；物理／法术专用屏障只吸收对应类型伤害。
- 独立资源与形态：玛露西尔魔力消耗、斩业星熊负生命承伤、结城理替身形态、维伊储能、飞行干员的起飞状态；伤害与控制走共享引擎，保留免疫、护盾、元素损伤和击杀结算。
- 自动战斗施放：连击、弹药、控制、持续伤害、治疗、范围增益与费用回复。召唤选点遵守可站立、空位和预留棋子位置限制，不能覆盖玩家已放置的单位。

## 代码入口与验证

`server/sim/content/kits/recruitsClassic.js`、`recruitsTactics.js`、`recruitsCombat.js`、`recruitsSummons.js`、`recruitsSpecial.js` 按角色返回选中技能的 spec；`recruitSupport.js` 提供范围、伤害、状态与生命周期工具。`content/index.js` 保留固定棋子优先级，再用 `charId` 解析新增候选。`shared/recruitMechanics.js` 仅供界面显示适配状态，测试检查它和实际注册表一致。

`test/content/recruits.test.js` 包含全部 936 种阶位／精锐／技能组合的施放与有限数值检查、选中技能可产生召唤物的生命周期，以及 Mon3tr、陈、棘刺、黑、赫拉格、林、年、死芒、令、多萝西、傀影、麦哲伦和玛露西尔的核心效果断言。继续补齐上述差异时，应新增行为断言，不能只增加“无报错”测试。
